# Legacy notebooks

These notebooks retain useful experimental workflows but are not maintained or
tested as tutorials. Prefer the numbered notebooks in the parent directory.

- `ck_interactive_monolith.ipynb` — the original monolithic interactive CK
  workflow, superseded by the focused notebooks and pipeline tutorial.
- `multilayer_focus_experiment.ipynb` — exploratory variable-Co-thickness and
  focal-plane analysis.
- `cobalt_energy_sweep_memory_safe.ipynb` — an alternate incremental-export
  implementation of the Co L-edge sweep.
- `cobalt_energy_sweep_energy_matched_pixels.ipynb` — an experimental Co
  L-edge sweep that changes sample pixel size with energy.
